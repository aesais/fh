## Control CamundaProcessInstanceViewer

| <center>Identifier </center> | <center>Type  </center> | <center> Boundable  </center> |  <center>DefaultValue </center>  | <center>Description  </center>                                                                                                                                                                       |  
|------------------------------|-------------------------|-------------------------------|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| processDefinitionBpmn        | String                  | true                          || Process definition BPMN                                                                                                                                                                              |
| bpmnActivityIds                  | List<String>            | true                          || List of activity identifiers (without incidents) that will cause proper BPMN elements to be marked with additional badge. Note -- these are equal to those ids as present in BPMN                    |
| incidentBpmnActivityIds          | List<String>            | true                          || List of incident activity identifiers that will cause proper BPMN elements to be marked with badge incident badge. Note -- these are equal to those ids as present in BPMN                           |
| selectedBpmnElementIdsChain       | List<String>            | true                          || chain of identifier of activities that will cause focus of Viewer to this element. Note -- this is equal to the id as present in BPMN. Chain is needed to make automatic drill down for subprocesses |
